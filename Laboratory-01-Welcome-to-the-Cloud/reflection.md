# Reflection — Laboratory 01

## What I Learned
In this first laboratory activity, I learned how to access and use a cloud-based Linux environment through KillerCoda. I was able to create a new user account, assign permissions, and switch between users. I also learned how to gather important system information such as OS version, kernel, CPU, memory, and disk space using simple commands.

Creating folder structures and writing Markdown files helped me understand how to organize work properly. Setting up the GitHub portfolio taught me how to structure a repository and write clean documentation, which I know will be very useful throughout the semester.

## Challenges Encountered
At first, remembering the exact commands and their options was a little confusing. But with practice and repetition, I became more comfortable navigating the terminal.

## How I Overcame Them
I took notes of each command and practiced them repeatedly. I also followed the instructions step-by-step and verified each output before moving to the next part.

## Conclusion
This activity gave me a solid introduction to the Linux environment, cloud-based workspaces, and GitHub. I feel more confident using the terminal now and understand why good file organization and documentation matter in technology.
